# Trellis

The product lives in [`trellis/`](./trellis) — see [`trellis/README.md`](./trellis/README.md)
for what it is, the architecture, and how to run it.

**Trellis** is a working MVP of an Asset Operating Company for real estate: a single
transparent performance score (the Trellis Score) and four connected stakeholder portals
(Owner/Investor, Resident, Vendor, Field Ops) running on one live dataset.
